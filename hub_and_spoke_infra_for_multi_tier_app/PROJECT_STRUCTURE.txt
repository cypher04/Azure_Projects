================================================================================
                              FILE DESCRIPTIONS
================================================================================

ENVIRONMENT FILES (env/*/):
─────────────────────────────────────────────────────────────────────────────────
main.tf          : Root module that creates resource group and calls all modules.
                   Also creates private endpoints and VNet integration at root
                   level to avoid circular dependencies between modules.

variables.tf     : Defines all input variables required for the environment:
                   resource_group, location, project_name, environment,
                   address_space, subnet_prefixes, delegation_subnet, etc.

outputs.tf       : Exposes key resource IDs and properties after deployment:
                   NSG ID, Public IP, Database ID, Resource Group details.

providers.tf     : Configures the Azure provider (azurerm ~> 3.0) with
                   required features block.

backend.tf       : Configures remote state storage (Azure Storage, S3, etc.)
                   for team collaboration and state locking.

terraform.tfvars : Environment-specific variable values. Contains sensitive
                   configuration like network CIDRs and project identifiers.

================================================================================
                           DEPLOYMENT ORDER
================================================================================

1. Resource Group    (created in main.tf)
2. Networking Module (VNets, Subnets, Peering, Public IP)
3. Database Module   (Cosmos DB Account, Database, Container)
4. Compute Module    (App Service Plan, Web App, DNS Zone)
5. Security Module   (NSGs, Rules, Associations, App Gateway, WAF)
6. Private Endpoints (App Service PE, Cosmos DB PE - in main.tf)
7. VNet Integration  (Swift Connection - in main.tf)
